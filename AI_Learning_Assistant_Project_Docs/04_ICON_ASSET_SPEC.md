# Icon & Brand Asset Specification

## Product
AI-Powered Interactive Learning Assistant

## Icon Style
- Outline-first
- Rounded geometry
- 2px stroke
- Minimal detail
- Consistent 24x24 grid
- Accessible at 16px and 20px
- No unnecessary gradients

## Core Product Icon
Combination of:
1. Play symbol
2. Conversation bubble
3. Learning/book/evidence cue

## Rules
- Use Lucide where an existing icon is sufficient.
- Create custom product marks only for branding.
- Do not mix multiple icon families.
- Keep stroke widths consistent.
