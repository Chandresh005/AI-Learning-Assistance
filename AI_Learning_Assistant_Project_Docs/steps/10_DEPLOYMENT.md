# Step 10 — Production Deployment

## Goal
Deploy a publicly accessible application.

## Development
- Docker Compose

## Production
Recommended AWS direction:
- S3
- Bedrock
- Transcribe
- RDS PostgreSQL
- ECS/Fargate
- API Gateway
- CloudWatch

## Tasks
- Configure production environment.
- Build containers.
- Configure HTTPS.
- Deploy frontend/backend.
- Configure storage/database.
- Configure monitoring.
- Run smoke tests.

## Definition of Done
Application is publicly accessible and deployment steps are documented.
