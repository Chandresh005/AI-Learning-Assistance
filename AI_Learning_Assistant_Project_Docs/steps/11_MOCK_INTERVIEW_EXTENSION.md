# Step 11 — AI Mock Interview Extension

## Start only after the core assistant is stable.

## Inputs
- Resume
- Target role
- Job description
- Course history
- Skill level
- Interview type

## Flow
Question → Candidate Answer → Analysis → Dynamic Follow-up → Repeat

## Output
- Overall score
- Technical knowledge
- Communication
- Problem solving
- Answer structure
- Strengths
- Improvement areas
- Preparation recommendations

## Optional
- Speech-to-text
- Text-to-speech
- Interview cost estimation

## Definition of Done
The interviewer dynamically adapts to previous answers and produces explainable feedback.
