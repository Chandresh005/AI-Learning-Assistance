# Step 01 — Repository & Environment

## Goal
Create the application skeleton.

## Tasks
1. Create Git repository.
2. Create `frontend/`.
3. Create `backend/`.
4. Create `data/`.
5. Create `evaluation/`.
6. Create `architecture/`.
7. Create `steps/`.
8. Add `.gitignore`.
9. Add `.env.example`.
10. Add README.

## Definition of Done
- Frontend and backend can start independently.
- Environment variables are documented.
- No secrets are committed.
